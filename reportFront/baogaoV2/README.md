# 长寿指数体检报告 UI V2

V2 根据第二张参考图重新设计，采用高级数据看板、非对称 Bento 网格与杂志式大字排版。上一版 V1 保持不变。

## 核心变化

- 顶部长寿指数采用数字递增、圆环绘制、轨道旋转、扫描高光四段式入场动效；动画完成后静止，并提供“重播动效”按钮。
- 八个模块不再共用同一张卡片模板：
  - 心血管：深色趋势折线图。
  - 肺功能：环形仪表与血氧条。
  - 消化系统：五阶段流程进度。
  - 内分泌：四象限能量矩阵。
  - 女性功能：周期轨道图。
  - 男性功能：垂直排版的非适用状态卡。
  - 免疫力：六节点防御网络。
  - 骨骼：四项密度柱状标尺。
- 所有模块仍可点击进入动态二级详情页。
- 支持 `prefers-reduced-motion`：用户开启“减少动态效果”时直接显示最终分数状态。

## V2.1 修改

- 系统卡片进入手机视口时播放一次专属数据动画；离开再返回不会重复播放。
- 当前演示用户为女性，首页只显示女性功能。男性用户场景应只显示男性功能，两者互斥。
- 色彩收敛为浅灰白、雾蓝和低饱和靛蓝；移除大面积深色、粉色和橙色背景。

## V2.2 修改

- 移除报告首页的应用导航栏，保留手机系统状态栏，让长寿指数直接成为首屏视觉中心。
- 在指数卡片右上角加入“保存报告”按钮；点击后下载当前报告长图，并显示“已保存”与轻量提示反馈。
- 二级详情页导航保持不变，便于用户返回报告首页。

## V2.3 交互约定（暂不绘制二级页）

- 点击任一系统卡片，通过模块 `id` 进入对应详情；返回时保留首页滚动位置。
- 首页模块图标、核心图表类型、当前分数和指标数据均带入二级页，形成视觉与数据连续性。
- `data.js` 已为每个系统补充 `visualization` 数据契约，后续详情页直接复用，不复制首页图表截图。
- 二级页的详细内容范围与各模块图表映射见 `二级详情页数据承接说明.md`；本轮不新增或修改二级详情页设计稿。

## V2.4 项目实现

- 首页系统卡片点击后，已在现有二级页框架内实际显示对应模块 SVG 图标。
- 二级页会根据 `visualization.type` 动态生成首页同类型图表，并展示完整数值标签；不是静态截图。
- 已实现折线、环形仪表、横向进度、四维矩阵、雷达、免疫网络和纵向柱状七类详情图表。
- 返回首页时恢复进入详情前的滚动位置；未对二级页进行独立视觉方案重设计。

## V2.5 AI 长寿咨询入口

- 报告首页新增“AI 长寿咨询”入口，延续 V2 的雾蓝、低饱和与轻量数据卡片风格。
- 入口展示本次 86 分报告的连接状态，并提供与报告数据相关的示例问题。
- 点击入口打开 `AI长寿咨询聊天页设计稿.png`，用于确认后续聊天产品界面方向。
- 本阶段仅交付聊天页静态设计稿，未编写聊天页面代码，也未接入 AI 对话功能。

## V2.6 悬浮入口

- 首页 AI 长寿咨询入口调整为固定悬浮胶囊，滚动报告时始终停留在右下安全区。
- 入口使用卡通医生头像与明确文字标签，触控区域大于 44px，并保留按压反馈及减少动态效果支持。
- 页面底部增加安全留白，避免悬浮入口遮挡尾部内容。

## V2.7 老年友好与营养支持推荐

- 面向老年用户重新校准首页字号：主要说明提升到 12–14px，图表辅助标签提升到 10–12px，交互文字同步放大。
- 首页新增“企业严选 · 专属营养支持方案”模块，结合身体系统数据呈现推荐逻辑，并可进入 AI 页面查看推荐依据。
- 产品视觉采用无品牌、无具体名称的深绿色金边高端礼盒，避免包装小字影响阅读。
- AI 聊天静态设计稿同步加入营养支持推荐，并放大正文、问题卡片与输入区文字。
- 首页和 AI 页面均展示合规提示：推荐仅供日常健康管理参考，保健食品不能替代药物治疗疾病。

## 文件

- `index.html`：V2 长寿指数报告首页。
- `detail.html`：通用二级详情页。
- `data.js`：八大系统演示数据。
- `app.js`：分数动效、重播控制与详情页数据装载。
- `styles.css`：V2 设计系统、图表和响应式样式。
- `AI长寿咨询聊天页设计稿.png`：AI 聊天页静态设计稿。
- `AI长寿咨询-卡通医生形象.png`：聊天页使用的透明背景卡通医生素材。
- `高端营养支持礼盒.png`：无品牌、透明背景的高端营养礼盒视觉素材。

演示数据仅用于 UI 展示，不构成医学诊断。
