# 三版报告 UI 客户评审预览包

整理日期：2026-10-21。来源：报告设计预览 airy-v4 版本。

## 部署文件

将 `report-ui-review/` 文件夹整体上传至测试站点静态目录，保留内部目录结构。文件夹内 12 个文件全部为运行必需资源。无需运行 npm install、npm build，无需后端接口、数据库、环境变量或外部 CDN；文字使用系统字体，图表以内联 SVG 和 CSS 绘制。

部署说明、资源清单、校验结果和 SHA256SUMS.txt 位于文件夹之外，仅供交付核对，无需上传至网站。

## 客户评审链接

假设上传后的目录为 `/report-ui-review/`，将下列路径加到测试站点域名之后：

| 入口 | 路径 |
| --- | --- |
| 三版切换总览 | `/report-ui-review/` |
| 方案一：轻盈健康 | `/report-ui-review/#light` |
| 方案二：器官画廊 | `/report-ui-review/#gallery` |
| 方案三：静谧数据 | `/report-ui-review/#data` |
| 方案一手机独立页 | `/report-ui-review/report-light.html` |
| 方案二手机独立页 | `/report-ui-review/report-gallery.html` |
| 方案三手机独立页 | `/report-ui-review/report-data.html` |

使用 HTTP/HTTPS 静态服务访问，入口为 index.html。三个页面与总览位于同一站点、同一目录，便于预览内切换、保存阅读进度与重播动画。可放在其他子目录，页面与图片地址均为相对路径。现有站点须按静态文件提供 .html、.css、.js、.png，避免将这些资源请求重写到业务系统首页。

## 包内内容

- 4 个 HTML：总览入口与三版独立报告。
- 2 个 CSS：预览基础样式与宽松布局。
- 2 个 JS：总览切换和报告动效。
- 4 张 PNG：医生头像、器官插画、睡眠管理方案礼盒、钙流失管理方案礼盒。

具体用途、大小和 SHA-256 校验值见“资源清单.json”。

## 评审范围

三版均完整展示 7 个系统、25 项指标、4 项直接采集结果和 2 项管理方案；包含图表入场、数值变化和 AI 常驻悬浮入口的滚动收展动画。总览提供 390/430px 预览宽度、独立打开、动画重播和 Tab 切换。

本包为固定示例数据的 UI 设计评审原型。AI 按钮用于展示收展交互，产品方案为视觉展示，未连接真实 AI 对话、商品详情或购买流程。三版配色保留各自的设计主题。

本包不包含 5176 正在运行的 Vue 业务项目，也不包含其蓝色 AI 入口业务改动；该项目是另一套运行和发布内容。历史探索图、生成提示词、长图压缩预览和旧版页面均未纳入部署包。

## 上传后的快速核对

1. 总览能切换三版，三个独立页都能打开。
2. 图片完整显示，每页包含全部七个系统，页面能够滚动到底。
3. 滚动时 AI 入口收起，停止约 1 秒后展开；图表动画和重播正常。
4. 手机独立页字号与图表正常，浏览器控制台没有资源加载错误。

本机复核可在本目录执行 `python3 -m http.server 5201 --bind 127.0.0.1`，随后访问 `http://127.0.0.1:5201/report-ui-review/`。
