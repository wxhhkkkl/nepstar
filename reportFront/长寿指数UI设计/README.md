# 长寿指数体检报告 UI 设计

本设计依据《抗衰健康指标_展现方案一_数据文档.xlsx》制作，使用参考图中的白色留白、薰衣草紫渐变、圆角卡片和轻量健康图表语言。

## 页面

- `index.html`：手机端长图报告首页，包含总指数、核心结论、8 个健康模块、90 天建议与底部行动入口。
- `detail.html`：通用二级详情页。首页任一模块卡片均可点击进入，并通过 URL 参数加载对应的指标、权重、采集结果、解读与行动建议。
- `assets/longevity-orbit.png`：为长寿指数主题生成的抽象生命轨道视觉。

## 演示口径

- 示例用户为女性，女性功能参与本次报告；男性功能保留入口但标记为“不适用”，以演示产品端按用户档案动态控制展示的方式。
- 评分型指标全部使用 60–100 活力值范围；微循环、心率、心电图、血氧饱和度作为采集结果直接显示，不参与加权。
- 页面数据为 UI 演示数据，不构成医学诊断。

## 设计系统

- 画布：390px 手机宽度，单列纵向滚动。
- 主色：`#7C4FE8`；背景：`#F6F4FB`；健康绿：`#167C67`。
- 卡片圆角：18–30px；间距遵循 4/8pt 节奏。
- 模块卡片触控区大于 44pt，带按压反馈、右箭头和明确的详情入口语义。
