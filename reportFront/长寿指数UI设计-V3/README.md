# 长寿指数体检报告 UI V3

V2 为已确认定稿版本，保持不变。V3 是依据新增参考图建立的独立视觉方案，采用薄荷绿健康渐变、白色信息卡、粗黑标题与绿色线性健康图标。

## V3 设计特征

- 首屏使用清透薄荷渐变与层叠白色评分卡，突出 86 分长寿指数和生理年龄差。
- 首页仅展示当前用户适用的女性专项模块，男性功能不同时出现。
- 七个身体系统采用七种不同图表：
  - 心血管：趋势面积折线图。
  - 肺功能：环形仪表与血氧进度。
  - 内分泌：四维热力矩阵。
  - 消化系统：五阶段横向进度流。
  - 女性功能：五维雷达图。
  - 免疫力：六节点防御网络。
  - 骨骼：四项纵向柱状标尺。
- 每张系统卡进入手机视口时播放一次专属数据动效；支持 `prefers-reduced-motion`。
- 每个系统卡片均可点击进入带图标、主图表、指标构成和健康建议的动态详情页。
- 保存报告按钮可直接下载 `长寿指数报告V3_手机长图.png`。

## 文件

- `index.html`：V3 手机长图报告首页。
- `detail.html`：动态二级详情页。
- `v3.css`：V3 视觉系统、七类图表与动效。
- `data.js`：身体系统及详情图表数据。
- `app.js`：评分、滚动动效、保存反馈和详情渲染。
- `render.mjs`：手机长图渲染与交互检查脚本。
- `AI长寿咨询聊天页设计稿.png`：AI 长寿咨询聊天页静态设计稿。
- `AI长寿咨询-卡通医生形象.png`：悬浮入口与聊天页使用的医生素材。

演示数据仅用于 UI 展示，不构成医学诊断。

## V3.1 响应式修改

- 项目根容器改为 `width: 100%`，桌面、平板和手机均铺满浏览器视口。
- 移除固定 390px 页面宽度及居中外边距，左右不再出现灰色留白。
- 已验证 1440、1024、390、375 四种宽度，页面无横向溢出。

## V3.2 AI 长寿咨询悬浮入口

- 将 V2 已定稿的 AI 长寿咨询功能原样复制到 V3：首页右下固定显示医生头像胶囊入口。
- 用户滚动长报告时入口始终可见，点击打开 `AI长寿咨询聊天页设计稿.png`。
- 入口适配手机安全区、44px 以上触控尺寸、按压反馈和减少动态效果。
- 保存报告提示调整到悬浮入口上方，避免两个固定元素相互遮挡。
- 当前仍仅提供聊天页静态设计稿，未接入 AI 对话功能。
