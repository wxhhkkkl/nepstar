```python
生产地址：xxxxx

```

###### 1. **公共参数约束**

​     **参数说明**

-  海王星辰接口请求参数分为系统参数与应用参数
- 系统参数：必传,包括appKey, timestamp , version ,sign
- 应用参数：请参照具体接口的参数定义

   **系统参数介绍**

| 参数名称  | 参数类型 | 必填 | 说明                                                         |
| --------- | -------- | ---- | ------------------------------------------------------------ |
| appKey    | string   | Y    | 每个合作方分配独立的appKey，作为合作方接入认证标识。每个appKey会绑定一个secret，用于计算签名 |
| timestamp | long     | Y    | 10位时间戳、格式为long，时区为GMT+8、开放平台允许合作方请求最大时间误差为10分钟 |
| version   | string   | Y    | API协议版本，可选值：1.0                                     |
| sign      | string   | Y    | API请求参数的签名计算结果                                    |

​    **返回说明**

- 返回结果采用 JSON 格式
- 包含code、msg、data字段

| 参数名称 | 参数类型 | 必填 | 说明                 |
| -------- | -------- | ---- | -------------------- |
| code     | string   | Y    | 0 标识成功，非0 失败 |
| message  | string   | Y    | 返回信息             |
| data     | string   | N    | 返回数据，json 格式  |

​    **签名说明**

- 将所有系统参数和业务参数(不包含sign,byte[]及值为空的参数)按照ASCII从小到大排序;
- 组装字符串，形成a=value1&b=value2的字符串S1;
- 末尾附加SECRET，组成S1& secret=xxxxxx 的形式，形成字符串S2;
- 对字符串S2 进行 MD5 加密，形成字符串S3（全大写）
- 对字符串S3 进行 sha1加密，形成字符串 S4（全大写）
- 将 S4 作为 sign 传入URL

​    **签名示例**

  假设请求参数如下

  secret=test

  系统参数：

```
  appKey=test
  timestamp= 1547795196
  version=1.0
```

  应用参数：

```
  type=1
  phone=13798261307
  password=
  openId=
  unionId=
```

- 取参数：

​    appKey, timestamp, version, type, phone

- 按照 ASCII 排序：

​    appKey，phone，timestamp，type , version

- 各字段拼接格式转换成

​    appKey=test&phone=13798261307&timestamp=1547795196&type=1&version=1.0

- 末尾添加 SECRET

​    appKey=test&phone=13798261307&timestamp=1547795196&type=1&version=1.0&secret=test

- 进行 MD5 加密（大写）

​    F7EB1EA5D9BD607CAFC4600B03F9811A

- 进行 sha1 加密（大写）得到 Sign

​    5F366AE0295C45AE78B11FC022199FBB0E5D4239
