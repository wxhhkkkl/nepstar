# AI 长寿顾问 UI 交互设计预览

这是产品设计阶段的独立高保真原型。所有报告数据、历史和回答均为本地样例，不读取真实报告、不调用 AI、不保存聊天、不修改业务数据库。用户已确认正式功能采用公开报告链接下的匿名咨询：当前标签页刷新可恢复聊天，关闭标签页后仅凭公开链接不能找回；本原型不模拟真实凭证隔离。

## 打开方式

在仓库根目录提供本地静态文件服务，然后访问：

- 三屏总览：`/specs/006-ai-longevity-consult/ui/board.html`
- 交互预览：`/specs/006-ai-longevity-consult/ui/index.html`
- 欢迎页：`index.html?view=welcome`
- 对话页：`index.html?view=chat`
- 网络异常：`index.html?view=error`
- 加载骨架屏：`index.html?view=loading`
- 首次使用说明：`index.html?view=consent`

例如在本机执行 `python3 -m http.server 5188 --bind 127.0.0.1 --directory /Users/leelee/Desktop/体检报告/nepstar`，再打开对应页面。

## 可体验交互

- 快捷提问、文字输入、示例答案逐步生成、停止与重新生成。
- 断网页面重新发送同一问题，保留用户消息。
- 报告依据展开/收起、报告摘要底部弹层。
- 会话记录、新建示例会话、首次使用说明。
- 复制回答、反馈选中状态、阅读历史时的新回复提示。

桌面左侧可切换页面状态；手机上隐藏设计工具栏，全宽展示界面。报告条、样例依据与对话操作处标识示例性质。

## 文件

- `index.html`：页面结构与静态状态模板。
- `styles.css`：局部样式、移动端布局、底部弹层和骨架屏。
- `prototype.js`：本地演示交互，不含业务请求。
- `board.html`：三屏并排评审画板。

复用项目现有的 AI 顾问形象。生产实现时应将已确认的结构迁入现有 Vue 3 + JavaScript 报告端，并按正式需求落实授权、真实数据、私聊历史、删除与模型调用；原型不是可上线的聊天服务。

- 在浏览器中检查 320、360、375、390、414、430 px 六种宽度，分别覆盖欢迎、对话、异常、骨架屏和说明弹层，共 30 个布局场景；未发现横向溢出。
- 已操作验证发送、停止、重新生成、展开依据、反馈状态、会话弹层、关闭与异常重试；重试没有重复增加用户消息。
- 用 390×480 缩小可视区模拟输入时的高度压力，底部输入区保持可见；未将这一检查等同于真实 iOS/Android 软键盘验收。
