# Quickstart: 单指标详情验收

1. 在 `reportFront/report-v2` 打开有真实报告参数的系统详情，点击一个已登记子指标，确认详情分数与列表一致。
2. 返回系统详情，确认阅读位置恢复；复制单指标 URL 在新页面直接打开也能显示同一指标。
3. 检查至少两次历史与首次检测两种样本：前者展示至多六个真实点，后者只显示“本次为首次有效记录”。
4. 在 `nepstarAdmin/frontend` 的指标管理编辑子指标解读和行动建议，再打开详情确认更新；清空后区块按空值规则隐藏。
5. 对未登记、停用、其他系统及其他客户的指标请求接口，确认不会泄露或回退。
6. 运行本地 mock 测试；检查新增服务代码对 `platform`、`kj_fastplus`、MongoDB 只有读取调用，不连接生产库执行测试或迁移。
